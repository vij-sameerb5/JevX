# helpdesk-demo

Tickets arrive from email and chat. Each one is routed to a team, given a priority, and the
customer's plan decides the SLA and the price of add-ons.

This is the **BEFORE** side of a JevX demo: all decisions are hardcoded. JevX should find
that ticket routing and urgency are judgment calls written as keyword rules, and leave the
exact logic (pricing, SLA hours, IDs) alone.
